Your first HTML element

The h1 element creates a main heading on your webpage.

Lesson 4: HTML Lists

HTML lists organize related information into groups.

Unordered List

Use <ul> for bulleted lists.

<ul>
        <li>HTML</li>
        <li>CSS</li>
        <li>JavaScript</li>
</ul>

Ordered List

Use <ol> for a numbered lists.

<ol>
    <li>Open your editor</li>
    <li>Write your code</li>
    <li>Preview your webpage</li>
</ol>

Lesson 5: HTML Tables

HTML Tables display information in rows and columns. They are useful for schedules, lists of data, and comparisons.

Basic Table Structure

The <table> element creates a table. The <tr> element creates a row, <th> creates a heading cell, and <td> creates a regular cell. 

<table>
    <tr>
        <th>Game</th>
        <th>Genre</th>
    </tr>
    <tr>
        <td>Roblox</td>
        <td>Sandbox</td>
    </tr>
    <tr>
        <td>Valorant</td>
        <td>Shooter</td>
    </tr>
</table>

Lesson 6: HTML Forms

HTML forms allows users to enter and sumbit information. You can use them for contact forms, registration pages, and other interactive features.

Basic Form Elements

The <form> element holds the form. The <label> describes an input, and <input> lets users enter data. The <button> creates a clickable button. 

<form>
    <label for="name">Your Name:</label>
    <input type="text" id="name" placeholder="Name">

    <button type="submit">Submit</button>
</form>

Lesson 7: Semantic HTML

Semantic HTML uses elements that describe the purpose of different parts of a webpage.

Common Semantic Elements

  • <header> — The top section of a page.
  • <nav> — Contains navigation links.
  • <main> — Contains the main content.
  • <section> — Groups related content.
  • <article> — Holds self-contained content.
  • <footer> — Contains footer information.

Example

<header>
    <h1>My Website</h1>
</header>

<nav>
    <a href="#About">About</a>
</nav>

<main>
    <section id="About">
        <h2>About Me</h2>
        <p>I am learning HTML!</p>
    </section>
</main>

<footer>
    <p>My Website</p>
</footer>

Lesson 8: Comments and Code Organization

Clean and organized code is easier to read, understand, and update. HTML comments let you leave notes in your code.

HTML Comments

Comments are notes that the browser does not display as normal webpage content. 

<!-- This is an HTML comment -->

<h1>Welcome to My Website</h1>

Organizing Your Code

Use indentation and spacing to make your code easier to read.

<section>
    <h2>About Me</h2>
    <p>I am learning web development.</p>
</section>

Good Coding Habits

  • Indent nested elements consistently.
  • Use meaningful names for IDs and classes.
  • Keep related elements together.
  • Use comments to explain important sections.
  • Close elements properly when required.
