Lesson 1: Introduction to JavaScript

JavaScript makes websites interactive. It can respond to clicks, update content, and more.

Example

console.log("Hello World!");

Lesson 2: Variables and Data Types

Variables store information. Use let for values that can change and const for values you don't plan to reassign.

Example

let name= "Alex";
const age = 16;
console.log(name);
console.log(age);
Next Lesson →

Lesson 3: Operators

Operators perform calculations and compare values.

Example

let a = 10;
let b = 5;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
Next Lesson →

Lesson 4: Conditions

Conditions let your program make decisions using if and else

Example

let score = 85;
if (score >= 75) {
    console.log("Passed!");
} else {
    console.log("Failed!");
}
Next Lesson →

Lesson 5: Loops

Loops repeat the instruction multiple times.

Example

for (let i = 1; i <= 5; i++) {
console.log(i);
}
Next Lesson →

Lesson 6: Functions

Functions let you reuse the code whenever you need it.

Example

function greet(name) {
console.log("Hello, " + name + "!")
}

greet("Alex");
Next Lesson →

Lesson 7: DOM Manipulation

The DOM lets JavaScript access and change the webpage elements.

Example

document.getElementById("message").textContent = "Welcome to Learn Code!";
Next Lesson →

Lesson 8: Events

Events let your website respond to actions such as button clicks.

Example

const button = document.getElementById("myButton");

button.addEventListener("click", function() {
    document.getElementById("message").textContent = "You clicked the button!";
});
