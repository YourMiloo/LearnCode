Lesson 1: Introduction to CSS

CSS stands for Cascading Style Sheets. It controls how HTML elements look, including colors, fonts, spacing, and layouts.

CSS Syntax

h1 {
    color: purple;
    font-size: 36px;
}
  • h1 is the selector.
  • color is a property.
  • purple is a value.
  • font-size changes text size.

Three Ways to Add CSS

Inline CSS:

<p style="color: purple;">Hello!</p>

Internal CSS:

<style>
p {
    color: purple;
}
</style>

External CSS:

<link rel="stylesheet" href="style.css">

External CSS lets multiple pages share the same stylesheet.

Lesson 2: Colors and Backgrounds

CSS lets you change text colors, background colors, and even create gradients.

Text and Background Colors

body {
    background-color: #121212;
}

h1 {
    color: #a78bfa;
}

p {
    color: white;
}

Different Ways to Set Colors

h1 {
    color: purple;
}

p {
    color: #ffffff;
}

button {
    background-color: rgb(124, 58, 237);
}

Background Gradients

body {
    background: linear-gradient(
        135deg,
        #121212,
        #302052
    );
}

Gradients smoothly blend two or more colors.

Lesson 3: Fonts and Text

CSS can change how text looks, how large it is, and how it is positioned.

Font Properties

h1 {
    font-family: Arial, sans-serif;
    font-size: 36px;
    font-weight: bold;
    text-align: center;
}

p {
    line-height: 1.6;
}
  • font-family chooses the font.
  • font-size changes text size.
  • font-weight controls thickness.
  • text-align aligns text.
  • line-height controls space between lines.

Decorating Text

a {
    text-decoration: none;
}

h2 {
    text-transform: uppercase;
}

Lesson 4: The CSS Box Model

Every HTML element is treated like a box. The box model includes content, padding, borders, and margins.

Example

.card {
    width: 250px;
    padding: 20px;
    border: 2px solid purple;
    margin: 15px;
}
  • Content: The text or other material inside.
  • Padding: Space between content and border.
  • Border: The outline around the element.
  • Margin: Space outside the border.

Rounded Corners

.card {
    background-color: #222;
    border-radius: 12px;
    padding: 20px;
}

Lesson 5: Flexbox and Grid

Flexbox and Grid help you arrange elements into organized layouts.

Flexbox

Flexbox is useful for arranging elements in a row or column.

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
}
  • display: flex enables Flexbox.
  • justify-content aligns items along the main axis.
  • align-items aligns items along the cross axis.
  • gap adds space between items.

CSS Grid

Grid is useful for layouts with rows and columns.

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

Lesson 6: Hover Effects and Transitions

Hover effects change an element's appearance when the pointer moves over it. Transitions make the change smoother.

Button Hover Effect

.button {
    background-color: #7c3aed;
    color: white;
    padding: 12px 20px;
    border-radius: 8px;
    transition: background-color 0.3s ease;
}

.button:hover {
    background-color: #5b21b6;
}

Moving a Card

.card {
    transition: transform 0.3s ease;
}

.card:hover {
    transform: translateY(-5px);
}

The card moves slightly upward when hovered over.

Lesson 7: Responsive Design

Responsive design makes websites adapt to different screen sizes, including phones, tablets, and computers.

Using Media Queries

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

@media (max-width: 768px) {
    .container {
        grid-template-columns: 1fr;
    }
}

When the screen is 768px wide or less, the layout changes to one column.

Responsive Images

img {
    max-width: 100%;
    height: auto;
}

Lesson 8: Animations and Final Project

CSS animations let elements change appearance or position over time without requiring JavaScript.

Creating an Animation

@keyframes fadeIn {
    from {
        opacity: 0;
        transform: translateY(10px);
    }

    to {
        opacity: 1;
        transform: translateY(0);
    }
}

.animated-card {
    animation: fadeIn 0.8s ease;
}

The card fades in while moving into its final position.

Animation Properties

  • @keyframes defines the animation steps.
  • animation-duration sets how long it runs.
  • animation-delay sets when it starts.
  • animation-iteration-count controls repetitions.
